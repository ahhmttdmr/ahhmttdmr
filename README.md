## Şu an

**[Opitekya](https://opitekya.com)** — ekipler ve topluluklar için güvenli, gerçek zamanlı iletişim platformu. Sesli sohbet, native GPU ile video/ekran yayını, anlık mesajlaşma ve masaüstü uygulaması. `production`
